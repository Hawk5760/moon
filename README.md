# Sheetal's Lunar Chronicle

Create a beautiful, cinematic birthday + hackathon congratulations website for Sheetal.

Theme

it is her birthday 🎂,Sheetal loves the moon 🌙, recently won a hackathon 🏆.

Make the website feel personal, nostalgic, elegant, and emotional, but not romantic or sad.

Visual Style

i have attached a image i want same to same exactly same UI/UX design 

fully responsive for mobile and desktop

Website Flow

1. Opening
Night sky + glowing moon.

Text:
“Tonight is a little different… Because tonight is about Sheetal.”

Button: Enter the night →

2. Birthday
“Happy Birthday, Sheetal 🌙🎂”

3. Hackathon Win
Futuristic transition.

“CONGRATULATIONS, SHEETAL! 🏆”

Show editable:

Hackathon name

Project name

Team name

Achievement

Hackathon photo

4. The Journey
Interactive timeline:
Idea → Build → Chaos → Pitch → WIN

5. Memories
Use moon phases to represent friendship:
🌑 Beginning → 🌒 Growing → 🌓 Crazy memories → 🌕 Best moments → 🌖 Things changed

Add editable photo gallery and captions.

6. Memory Quiz
5 fun “Do you remember?” questions with animations.

7. Letter Under the Moon 💌
Animated envelope that opens into a heartfelt birthday + congratulations message. Keep it mature and respectful.

8. Same Moon 🌕
Main emotional line:

“We may not stand in the same place anymore… but we're still under the same moon.”

Follow with a positive wish for her future.

9. Final Celebration
Moon transforms into a birthday cake + trophy.

“Happy Birthday, Sheetal 🎂🌙”
“And congratulations, Hackathon Winner! 🏆”

Click candles → confetti + stars + celebration.

10. Ending
Quiet moonlit sky:

“Some chapters end. Some memories don't.”

“Keep building. Keep dreaming. Keep looking up. 🌙”

Important

Make all personal content editable from one configuration section:
name, photos, memories, hackathon details, quiz, letter, music.

Add:

music toggle

smooth scrolling

moon-phase navigation

responsive design

working animations

replay button

Do NOT make it look like a generic birthday template. Make it feel like a personal story created especially for Sheetal.
